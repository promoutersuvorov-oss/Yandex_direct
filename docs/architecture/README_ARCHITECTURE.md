# KEY Architecture Index

Architecture contracts are grouped by product capability. This index is the entry point; a target architecture does not mean that an integration is already live.

## Generator foundation — current priority
- [Customer Experience Architecture](CUSTOMER_EXPERIENCE_ARCHITECTURE.md) — buyer journey, value exchange, qualification and conversion metrics.
- [Data Model Specification](DATA_MODEL_SPEC.md) — canonical project facts and runtime mapping.
- [Landing Module Registry](KEY_LANDING_MODULE_REGISTRY_V1.md) — reusable modules and stable identities.
- [Positioning Gate](POSITIONING_GATE.md) — evidence required before production positioning.
- [Commercial Snapshot Contract](COMMERCIAL_SNAPSHOT_CONTRACT.md) — dated offers/inventory and publication safety.
- [KEY CRM API handoff contract](KEY_CRM_API_HANDOFF_CONTRACT.md) — lead payload and future CRM intake boundary.

## Post-generator growth integration — prepare now, implement in phases
- [Closed-Loop Growth & Conversion Intelligence](CLOSED_LOOP_GROWTH_ARCHITECTURE.md) — event taxonomy, attribution, consent, Metrica/behavioural analysis, CRM outcomes, Yandex conversion feedback, AI analysis and controlled experiments.

## Implementation rule
Complete and stabilize the generator first. Preserve the versioned integration seams in the post-generator architecture, but do not build speculative services or activate third-party tracking before technical, privacy and business gates are met.
