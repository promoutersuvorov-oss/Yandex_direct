# ЖК «Галилей» — media rights gate

**Дата проверки:** 2026-11-06  
**Статус:** media candidates identified; publication rights not confirmed  
**Scope:** internal KEY review only. No image from the developer website is approved for reuse by this record.

## Primary source and rights restriction

The official project page contains project-specific image material for the exterior/gallery, landscape design, car-free courtyard, landscaping, dry fountain, common areas, architecture, terraces, and finishing examples:

- https://www.krays.ru/object/galiley

The same page states in its footer:

> Запрещено использование материалов сайта без согласия ООО УК «Крайс» и ссылки на сайт.

Therefore, public accessibility and confirmation that an image depicts ЖК «Галилей» do **not** establish permission to copy, crop, host, or publish it in a KEY landing page or advertising. A source link alone is not sufficient; written permission from the rights holder is required.

An official developer photo report also exists:

- https://www.krays.ru/blog/fotootchet-so-stroyploshchadki-zhk-galiley
- Published 05.02.2026; describes photographs of the building, Bavarian brick facade, windows, and courtyard/landscape.

This article is a useful lead for identifying authentic project photography, but it does not independently grant reuse rights.

## Recommended media request

Ask the developer for original, high-resolution assets and written usage permission for the following set:

| Priority | Requested material | Intended KEY use |
|---|---|---|
| P0 | Best current exterior / full-complex view | Hero or first major visual |
| P0 | Internal garden and landscape, wide and detail frames | Signature lifestyle section |
| P0 | Courtyard and dry fountain | Main project differentiator |
| P1 | Bavarian brick facade, close-up and full elevation | Architecture section |
| P1 | Common areas / lobby / entrance | Everyday-life section |
| P1 | Terrace examples | Conditional apartment-format section |
| P2 | Finishing examples (clean finish and White-box) | Finishing comparison, only with clear labels |
| P2 | Current approved floor-plan graphics | Apartment-plan module, separately evidence-checked |

Prefer a coherent set from the same current project phase rather than mixing renders, construction photos, and finished photography without labels.

## Permission checklist

Before any asset is added to the publishable passport, obtain confirmation of:

1. Rights holder and the person/entity authorized to grant permission.
2. Permission to use the materials on KEY landing pages and in KEY advertising.
3. Permission to download, store, crop, resize, compress, and make responsive derivatives.
4. Required attribution wording and whether a link to the developer is mandatory.
5. Allowed channels, territories, and permission term / expiry.
6. Whether the image is a render, construction photo, completed-project photo, or illustrative finishing example.
7. Confirmation that each file depicts ЖК «Галилей» and identification of the relevant building/area where applicable.

Keep the permission email/letter or license as traceable evidence. Record source, rights evidence, project match, usage, and expiry on each asset.

## Renderer gate

Until permission is received:

- keep `assets.images` empty for the Galiley public profile;
- do not copy image URLs from the developer page into an approved asset record;
- do not use search-engine thumbnails, stock imagery, or generated architecture as substitutes;
- keep the hero in its existing text-only architectural composition;
- do not mark `rightsStatus` as `confirmed` or asset `status` as `approved`.

After permission is received, add each asset with `projectMatch: confirmed`, `rightsStatus: confirmed`, a traceable `rightsSource`, `rightsNote`, intended `usage`, and an appropriate `validUntil` if the grant is time-limited. Then assign only approved assets to the relevant modules and run desktop/mobile visual review.
